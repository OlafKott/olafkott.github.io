Tipp: Immer zuerst n (die große Zahl), dann der Befehl, dann r. Riesige Ergebnisse zeigt der Rechner mit ×10… an.

1Fakultät n!✍ nach Tour-Teil 1

Alle n Objekte werden in eine Reihenfolge gebracht:

n! = n · (n − 1) · … · 2 · 1

a)5! =120
b)7! =5040
c)10! =3628800
2Variation nPr: Auswahl, Reihenfolge wichtig✍ nach Tour-Teil 2

Aus n Objekten werden r geordnet ausgewählt (z. B. Plätze, Ämter):

n P r = n!(n − r)!

a)6 P 2 =30
b)10 P 3 =720
c)15 P 4 =32760
3Binomialkoeffizient nCr: Auswahl, Reihenfolge egal✍ nach Tour-Teil 3

Aus n Objekten werden r ohne Reihenfolge ausgewählt (z. B. Gruppe, Lotto). Die Anzahl heißt Binomialkoeffizient („n über r“), am Rechner n C r:

n C r = (nr) = n!r! · (n − r)!

a)6 C 2 = (62) =15
b)10 C 3 = (103) =120
c)15 C 4 = (154) =1365
