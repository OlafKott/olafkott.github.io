Gliederung für Moodle

Der Code nutzt nur Tabellen und Inline-Styles – genau das, was Moodle in Textfeldern zulässt (geprüft mit dem Moodle-HTML-Filter). Alle Buttons öffnen die Seiten in einem neuen Tab.

  1. In Moodle eine Textseite oder ein Textfeld anlegen.
  2. Im Editor auf Quellcode / HTML umschalten (Symbol </>).
  3. Code einfügen (ein Klick ins Feld markiert alles) und speichern.

So sieht es in Moodle aus
