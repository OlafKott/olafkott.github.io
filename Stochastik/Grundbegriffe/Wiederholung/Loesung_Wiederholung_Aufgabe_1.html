1Ein Würfel – vier Stationen

a)Zufallsexperiment ja — der Wurf ist beliebig oft unter gleichen Bedingungen wiederholbar, der Ausgang ist aber nicht vorhersehbar.
Ω = {1, 2, 3, 4, 5, 6}
b)
A = {2, 4, 6},   B = {5, 6}
A ∩ B = {6}  ·  A ∪ B = {2, 4, 5, 6}  ·  A = {1, 3, 5}
c)Laplace-Experiment ja — beim idealen Würfel sind alle sechs Augenzahlen gleich wahrscheinlich.
P(A) = 36 = 12  ·  P(B) = 26 = 13
d)Additionssatz:
P(A ∪ B) = P(A) + P(B) − P(A ∩ B) = 36 + 26 − 16 = 46 = 23
Kontrolle durch Abzählen: A ∪ B = {2, 4, 5, 6} hat 4 Elemente → 46 = 23 ✓
P(A) = 1 − P(A) = 1 − 12 = 12
e)z. B. C = „eine 1“ = {1} und D = „eine 2“ = {2}. Sie sind unvereinbar, da C ∩ D = { } (beide können nicht gleichzeitig eintreten). Dann ist P(C ∩ D) = 0, im Additionssatz fällt der Abzug weg:
P(C ∪ D) = P(C) + P(D) = 16 + 16 = 26 = 13
