Aufgabe 2 Funktionsgleichung aufstellen – Parabel durch 3 Punkte

Punkte:  P1(−1 | 0),  P2(1 | 4),  P3(3 | 0)

Ansatz:  f(x) = ax² + bx + c

Einsetzen der drei Punkte liefert das LGS:

{ (I) a − b + c = 0
(II) a + b + c = 4
(III) 9a + 3b + c = 0

Lösung des LGS:

(II) − (I): 2b = 4 ⟹ b = 2
(III) − (II): 8a + 2b = −4 → 8a = −8 ⟹ a = −1
in (I): −1 − 2 + c = 0 ⟹ c = 3
f(x) =   −x² + 2x + 3

Probe:

f(−1) = −1 − 2 + 3 = 0 ✓  P1(−1 | 0)
f(1) = −1 + 2 + 3 = 4 ✓  P2(1 | 4)
f(3) = −9 + 6 + 3 = 0 ✓  P3(3 | 0)
Aufgabe 3 Zuordnung – Welches LGS gehört zu welcher Parabel?

Tipp zur Zuordnung: Setze in den Ansatz f(x) = ax² + bx + c die Punkte ein. Der x = 0 -Punkt liefert direkt c. Daran erkennt man oft das passende LGS schnell.

a) Zuordnung:

Parabel A B C
passendes LGS ② ③ ①

Begründung: Parabel A hat P(0|3) → c = 3 (passt zu LGS ② mit „c = 3"). Parabel B hat ebenfalls P(0|3) → c = 3, aber die anderen Punkte passen zu LGS ③. Parabel C hat keinen x=0-Punkt; bleibt LGS ① übrig.

b) Funktionsgleichungen mit dem CAS:

Parabel A: P1(0 | 3), P2(1 | 0), P3(2 | −1) ⟹ f(x) = x² − 4x + 3
Parabel B: P1(−1 | 0), P2(0 | 3), P3(3 | 0) ⟹ f(x) = −x² + 2x + 3
Parabel C: P1(1 | 0), P2(2 | 3), P3(3 | 8) ⟹ f(x) = x² − 1
Aufgabe 4 Funktionsgleichung aufstellen – Funktion 3. Grades durch 4 Punkte

Punkte:  P1(0 | −2),  P2(1 | 0),  P3(2 | 8),  P4(−1 | −4)

Ansatz:  f(x) = ax³ + bx² + cx + d

Einsetzen liefert das LGS:

{ (I) d = −2
(II) a + b + c + d = 0
(III) 8a + 4b + 2c + d = 8
(IV) −a + b − c + d = −4

Lösung mit dem CAS:

solve({d = −2, a + b + c + d = 0, 8a + 4b + 2c + d = 8, −a + b − c + d = −4}, {a, b, c, d})
Koeffizienten:   a = 1  ,  b = 0  ,  c = 1  ,  d = −2
f(x) =   x³ + x − 2

Probe:

f(0) = 0 + 0 − 2 = −2 ✓  P1(0 | −2)
f(1) = 1 + 1 − 2 = 0 ✓  P2(1 | 0)
f(2) = 8 + 2 − 2 = 8 ✓  P3(2 | 8)
f(−1) = −1 − 1 − 2 = −4 ✓  P4(−1 | −4)
Aufgabe 5 Anwendung – Kostenfunktion eines Betriebs

Ansatz:  K(x) = ax³ + bx² + cx + d

a)

Einsetzen der vier Wertepaare in den Ansatz:

K(1) = 110: a · 1 + b · 1 + c · 1 + d = 110 ⟹ a + b + c + d = 110
K(2) = 114: a · 8 + b · 4 + c · 2 + d = 114 ⟹ 8a + 4b + 2c + d = 114
K(3) = 118: a · 27 + b · 9 + c · 3 + d = 118 ⟹ 27a + 9b + 3c + d = 118
K(5) = 150: a · 125 + b · 25 + c · 5 + d = 150 ⟹ 125a + 25b + 5c + d = 150

Lineares Gleichungssystem:

{ (I) a + b + c + d = 110
(II) 8a + 4b + 2c + d = 114
(III) 27a + 9b + 3c + d = 118
(IV) 125a + 25b + 5c + d = 150
b)

Lösung mit dem CAS:

Koeffizienten:   a = 1  ,  b = −6  ,  c = 15  ,  d = 100
K(x) =   x³ − 6x² + 15x + 100
c)

Erwartete Kosten bei x = 4 ME:

K(4) = 4³ − 6 · 4² + 15 · 4 + 100
= 64 − 96 + 60 + 100
= 128 €

Bei einer Produktionsmenge von 4 ME erwartet man Gesamtkosten von 128 €.

d)

Wirtschaftliche Bedeutung des Koeffizienten d = 100:

Setzt man x = 0 (also: es wird nichts produziert) in die Kostenfunktion ein, erhält man:

K(0) = 0 − 0 + 0 + 100 = 100 €

Interpretation: Der Koeffizient d = 100 € entspricht den Fixkosten — das sind Kosten, die unabhängig von der Produktionsmenge anfallen (z. B. Miete, Versicherungen, Abschreibungen). Sie entstehen auch dann, wenn keine Einheit produziert wird.
