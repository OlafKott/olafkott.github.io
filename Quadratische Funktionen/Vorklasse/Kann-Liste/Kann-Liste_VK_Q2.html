1.2… bei einer quadratischen Funktion f(x) = ax² + bx + c die Zahlen a, b und c ablesen.
f(x) = −2x² + 3x − 5
→ a = −2, b = 3, c = −5
f(x) = x² − 4
→ a = 1, b = 0, c = −4		Die Zahl vor x² ist a. Die Zahl vor x ist b. Die Zahl ohne x ist c.
Das Vorzeichen gehört immer dazu. Steht kein x, ist b = 0.
Arbeitsblatt · Teil 2
1.3… erklären, wie a und c die Parabel verändern.
f(x) = 2x²: schmaler. g(x) = −0,5x² + 4: nach unten, breiter, 4 nach oben.
a > 0: nach oben geöffnet. a < 0: nach unten geöffnet.
a größer als 1 (ohne Minus): schmaler (gestreckt).
a zwischen 0 und 1: breiter (gestaucht).
c: Schnittpunkt mit der y-Achse (0 | c).

2. Punkte eintragen.
3. Mit einem runden Bogen verbinden, nicht mit dem Lineal.

4. Quadratische Gleichungen lösen
Nr.Ich kann …BeispielSo geht’s / Merke
4.1… einfache quadratische Gleichungen durch Wurzelziehen lösen.
2x² − 18=0| + 18
2x²=18| : 2
x²=9| √
x₁=3 ∨ x₂ = −3
Geht, wenn es kein Glied mit x gibt (nur x² und eine Zahl).
x² allein stellen, dann Wurzel ziehen.
Es gibt zwei Lösungen: + und −.
x² = −4: keine Lösung. Eine Zahl hoch 2 ist nie negativ.
Präsentation · Teil 5
4.2… quadratische Gleichungen mit der pq-Formel lösen.
x² − 2x − 15=0
p=−2;   q = −15
x₁,₂=1 ± 1 + 15
=1 ± 4
x₁=5 ∨ x₂ = −3
Vor x² muss eine 1 stehen. Sonst zuerst durch a teilen.
x₁,₂ = −p2 ± (p2)² − q
Vorzeichen von p und q mitnehmen!
Schablone · Teil 5
4.3… an der Zahl unter der Wurzel erkennen, wie viele Lösungen es gibt.
positiv: 2
0: 1
negativ: 0
Unter der Wurzel steht eine …
positive Zahl → 2 Lösungen
0 → 1 Lösung
negative Zahl → keine Lösung
Beispiel · Teil 5
4.4… die Nullstellen einer quadratischen Funktion berechnen.
f(x) = −x² + 2x + 3
−x² + 2x + 3=0| : (−1)
x² − 2x − 3=0
x₁=3 ∨ x₂ = −1
N₁(3 | 0), N₂(−1 | 0)
Nullstellen: Hier schneidet die Parabel die x-Achse.
Ansatz: f(x) = 0. Dann Wurzelziehen oder pq-Formel.

5. Schnittpunkte berechnen
Nr.Ich kann …BeispielSo geht’s / Merke
5.1… die Schnittpunkte einer Parabel und einer Geraden berechnen.
f(x) = x² + 2x − 1, g(x) = 2x + 3
x² + 2x − 1=2x + 3| − 2x − 3
x² − 4=0| + 4
x²=4| √
x₁=2 ∨ x₂ = −2
g(2) = 7, g(−2) = −1 → S₁(2 | 7), S₂(−2 | −1)
1. Gleichsetzen: f(x) = g(x).
2. Alles auf eine Seite: … = 0.
3. Lösen (Wurzel oder pq-Formel).
4. x-Werte in f oder g einsetzen → y-Werte.
Schablone · Teil 5
5.2… die Schnittpunkte von zwei Parabeln berechnen.
f(x) = x² + 1, g(x) = −x² + 3
x² + 1=−x² + 3| + x² − 1
2x²=2| : 2
x²=1| √
x₁=1 ∨ x₂ = −1
f(1) = 2, f(−1) = 2 → S₁(1 | 2), S₂(−1 | 2)
Genauso wie bei Parabel und Gerade: gleichsetzen.
Haben beide dasselbe x², fällt x² weg. Dann ist es eine lineare Gleichung mit nur einer Lösung.
Schablone · Teil 5
5.3… erkennen, ob Parabel und Gerade zwei Schnittpunkte, einen Berührpunkt oder keinen gemeinsamen Punkt haben.
2 Punkte
Berührpunkt
kein Punkt
Nach dem Gleichsetzen und der pq-Formel:
2 Lösungen → 2 Schnittpunkte
1 Lösung → 1 Berührpunkt
keine Lösung → kein gemeinsamer Punkt
