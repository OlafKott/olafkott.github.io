1Warum umformen?

Eine Parabel kann man auf zwei Arten aufschreiben.

Scheitelpunktform

f(x) = (x − 3)² + 2
Hier liest du den Scheitelpunkt ab: S(3 | 2)

Allgemeine Form

f(x) = x² − 6x + 11
Hier liest du c ab: (0 | 11) auf der y-Achse.
Die beiden Graphen sind gleich. Beide Gleichungen beschreiben dieselbe Parabel.

2Zwei Formen, eine Parabel

Heute lernst du den Weg von der Scheitelpunktform zur allgemeinen Form.
Das ist der lila Pfeil.

3Die binomischen Formeln

Binomische Formeln
1.  (a + b)² = a² + 2ab + b²
2.  (a − b)² = a² − 2ab + b²
Beispiel: (x + 3)²
Das Quadrat hat 4 Teile:
(x + 3)²=x² + 3x + 3x6x + 9=x² + 6x + 9zusammenfassen
Achtung, Falle: (x + 3)² ist nicht x² + 9.
Sonst fehlt der mittlere Teil 6x.

4Binomische Formeln Schritt für Schritt

(a − b)²=a² − 2 · a · b + b²2. Formel allgemein(x − 4)²=x² − 2 · x · 48x + 4²16a = x und b = 4 einsetzen=x² − 8x + 16
(a + b)²=a² + 2 · a · b + b²1. Formel allgemein(x + 5)²=x² + 2 · x · 510x + 5²25a = x und b = 5 einsetzen=x² + 10x + 25
Achte auf das Vorzeichen in der Klammer:
Es steht auch vor dem mittleren Teil.

So rechnet man ausführlich:

(x − 4)²=(x − 4) · (x − 4)ausführlich=x · xx² − x · 4−4x − 4 · x−4x + 4 · 4+16jedes mit jedem=x² − 4x − 4x−8x + 16=x² − 8x + 16✓ gleiches Ergebnis

10Der Rückweg

Den Weg von der allgemeinen Form zurück zur Scheitelpunktform gibt es auch.
Nur zur Info: Der Rückweg heißt quadratische Ergänzung.
Den brauchst du in dieser Reihe nicht.

★Jetzt du

Forme um: f(x) = 3(x − 1)² + 2
f(x) = 3 · ( x² x ) + 2  binomische Formel
f(x) = 3x² x + 2  ausmultiplizieren
f(x) = 3x² x  zusammenfassen
Das brauchst du:
(a − b)² = a² − 2ab + b²
(a + b)² = a² + 2ab + b²
