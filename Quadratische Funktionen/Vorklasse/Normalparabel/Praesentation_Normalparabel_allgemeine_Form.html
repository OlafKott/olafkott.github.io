1Die Normalparabel

Die einfachste quadratische Funktion ist:
f(x) = x²
x² heißt: x · x. Man rechnet die Zahl mal sich selbst.
Beispiel: 3² = 3 · 3 = 9
Die Funktion f(x) = x² heißt Normalparabel.

Warum „quadratisch“?

Darum heißt x² auch „x Quadrat“.

4Eigenschaften der Normalparabel

1
Scheitelpunkt: Der tiefste Punkt heißt Scheitelpunkt S. Bei der Normalparabel ist S(0 | 0).
2
Nach oben geöffnet: Die Öffnung zeigt nach oben. Die Parabel ist wie eine Schale: Du könntest oben Wasser hineinfüllen.
3
Symmetrisch: Die y-Achse teilt die Parabel in zwei gleiche Hälften. Links und rechts sind die Werte gleich: f(−2) = 4 und f(2) = 4.
4
Nie negativ: Eine Zahl mal sich selbst ist nie negativ: (−3)² = 9. Darum liegt die Parabel immer oberhalb der x-Achse. Nur S berührt sie.

5Die Normalparabel schnell zeichnen

Links geht es genauso. Die Parabel ist ja symmetrisch.
Tipp: So kannst du prüfen, ob ein Graph die Normalparabel ist.

6Die allgemeine Form

Es gibt viele quadratische Funktionen. Alle haben diese Form:
Allgemeine Form einer quadratischen Funktion:
f(x) = ax² + bx + c
Wichtig: a darf nicht 0 sein. Sonst gibt es kein x².
f(x) = 2x² + 3x − 1
a = 2   b = 3   c = −1
Das Minus gehört zur Zahl.
f(x) = −x² + 4
a = −1   b = 0   c = 4
Nur ein Minus vor x²: a = −1.
Kein x-Teil: b = 0.
f(x) = 0,5x² − 2x
a = 0,5   b = −2   c = 0
Keine Zahl ohne x: c = 0.
So liest du a, b und c ab: Steht nichts vor x², dann ist a = 1. Das Vorzeichen gehört immer zur Zahl.

10Was macht der Parameter a? f(x) = a · x²

Ziehe den roten Punkt auf dem Zahlenstrahl. Die gestrichelte Kurve ist die Normalparabel.
f(x) = 0,5x²
a = 2a = 1a = 0,5a = −0,5a = −1a = −3

11Teste dich: Parameter a

Wie sieht der Graph von f(x) = −4x² aus?
Anach oben geöffnet, gestreckt
Bnach unten geöffnet, gestreckt
Cnach unten geöffnet, gestaucht
a = −4: a ist negativ, also nach unten. 4 ist größer als 1, also gestreckt (schmaler).
Welche Parabel ist breiter als die Normalparabel?
Af(x) = 3x²
Bf(x) = −0,4x²
Cf(x) = −x²
Ohne Minus ist 0,4 kleiner als 1. Die Parabel ist gestaucht, also breiter.

12Was macht der Parameter c? f(x) = ax² + bx + c

Hier siehst du eine Funktion in allgemeiner Form. Achte auf c und auf den orangen Punkt.
Andere Funktion ▶
c1
Warum? Setze x = 0 ein: f(0) = a · 0² + b · 0 + c = c

13Teste dich: Parameter c

c ist der y-Achsenabschnitt: Der Graph schneidet die y-Achse in (0 | c).
c größer: Parabel nach oben.   c kleiner: Parabel nach unten.
Wo schneidet der Graph die y-Achse?
f(x) = 2x² − 3x + 5  →  ( 0 | )
f(x) = −x² + 4x  →  ( 0 | )
Die Parabel f(x) = x² + 1 wird um 3 nach unten verschoben. Welche Funktion entsteht?
Af(x) = x² + 4
Bf(x) = x² − 2
Cf(x) = x² − 3
c = 1 − 3 = −2. Also f(x) = x² − 2.
Tipp: Fehlt c, dann ist c = 0. Der Graph geht durch (0 | 0).

14a und c am Graphen erkennen

Diese Parabel kannst du jetzt beschreiben:
1
Sie ist nach unten geöffnet. Also ist a negativ.
2
Sie ist breiter als die Normalparabel. Sie ist gestaucht.
3
Sie schneidet die y-Achse bei 2. Also ist c = 2.
Welche Gleichung passt zu der Parabel?
Af(x) = −0,5x² + 2
Bf(x) = 0,5x² + 2
Cf(x) = −2x² + 2
Df(x) = −0,5x² − 2
Nach unten: a ist negativ. Breiter: a ist zwischen −1 und 0. y-Achse bei 2: c = 2.

★Zusammenfassung

Das hast du gelernt:
  • Normalparabel: f(x) = x² mit S(0 | 0)
  • Allgemeine Form: f(x) = ax² + bx + c
  • a: oben oder unten, gestreckt oder gestaucht
  • c: Schnittpunkt mit der y-Achse
