1Die Normalparabel

Die einfachste quadratische Funktion ist:
f(x) = x²
x² heißt: x · x. Man rechnet die Zahl mal sich selbst.
Beispiel: 3² = 3 · 3 = 9
Die Funktion f(x) = x² heißt Normalparabel.

Warum „quadratisch“?

Darum heißt x² auch „x Quadrat“.

4Eigenschaften der Normalparabel

Die Normalparabel hat wichtige Eigenschaften:
  • Der tiefste Punkt heißt Scheitelpunkt S.
    Bei der Normalparabel ist S(0 | 0).
  • Die Parabel ist nach oben geöffnet.
  • Sie ist symmetrisch zur y-Achse.
    Links und rechts sind die Werte gleich.
  • Die y-Werte sind nie negativ.

6Die allgemeine Form

Es gibt viele quadratische Funktionen. Alle haben diese Form:
Allgemeine Form einer quadratischen Funktion:
f(x) = ax² + bx + c
Wichtig: a darf nicht 0 sein. Sonst gibt es kein x².
f(x) = 2x² + 3x − 1
a = 2   b = 3   c = −1
Das Minus gehört zur Zahl.
f(x) = −x² + 4
a = −1   b = 0   c = 4
Nur ein Minus vor x²: a = −1.
Kein x-Teil: b = 0.
f(x) = 0,5x² − 2x
a = 0,5   b = −2   c = 0
Keine Zahl ohne x: c = 0.
So liest du a, b und c ab: Steht nichts vor x², dann ist a = 1. Das Vorzeichen gehört immer zur Zahl.

10Was macht der Parameter a? f(x) = a · x²

Zahl ohne Minus größer als 1: gestreckt (schmaler).
Zahl ohne Minus kleiner als 1: gestaucht (breiter).

12a und c am Graphen erkennen

Diese Parabel kannst du jetzt beschreiben:
1
Sie ist nach unten geöffnet. Also ist a negativ.
2
Sie ist breiter als die Normalparabel. Sie ist gestaucht.
3
Sie schneidet die y-Achse bei 2. Also ist c = 2.
Welche Gleichung passt zu der Parabel?
Af(x) = −0,5x² + 2
Bf(x) = 0,5x² + 2
Cf(x) = −2x² + 2
Df(x) = −0,5x² − 2
Nach unten: a ist negativ. Breiter: a ist zwischen −1 und 0. y-Achse bei 2: c = 2.

★Zusammenfassung

Das hast du gelernt:
  • Normalparabel: f(x) = x² mit S(0 | 0)
  • Allgemeine Form: f(x) = ax² + bx + c
  • a: oben oder unten, gestreckt oder gestaucht
  • c: Schnittpunkt mit der y-Achse
