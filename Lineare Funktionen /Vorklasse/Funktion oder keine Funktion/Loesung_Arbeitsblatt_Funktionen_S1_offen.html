Lösung – Arbeitsblatt: Funktion oder keine Funktion?

Zuordnungen und Funktionen · Stunde 1
Formulierungshilfe – so begründen Sie
Sachtext: Jedem … kann nur genau ein … zugeordnet werden.  /  Einigen … können mehr als ein … zugeordnet werden.
Wertetabelle: Jedem Argument wird genau ein Funktionswert zugeordnet.  /  Dem Argument x = … wird mehr als ein Funktionswert zugeordnet.
Graph: Jedem x-Wert wird genau ein y-Wert zugeordnet.  /  Dem Argument x = … wird mehr als ein Funktionswert zugeordnet.
Die Sätze stehen auch auf Ihrem Vorbereitungsblatt.

1   Sachtext

Kreuzen Sie an und begründen Sie mit einem Satz.

a) „Jeder Person wird ihre Körpergröße zugeordnet.“

✗Funktionkeine Funktion
Jeder Person kann nur genau eine Körpergröße zugeordnet werden.

b) „Jeder Körpergröße wird eine Person zugeordnet.“

Funktion✗keine Funktion
Einigen Körpergrößen können mehr als eine Person zugeordnet werden.

c) „Jedem Datum wird sein Wochentag zugeordnet.“

✗Funktionkeine Funktion
Jedem Datum kann nur genau ein Wochentag zugeordnet werden.

2   Wertetabelle

Kreuzen Sie an und begründen Sie mit einem Satz.

a)
x1234
y2468
✗Funktionkeine Funktion
Jedem Argument wird genau ein Funktionswert zugeordnet.
b)
x2446
y1357
Funktion✗keine Funktion
Dem Argument x = 4 wird mehr als ein Funktionswert zugeordnet (3 und 5).
c)
x1234
y7777
✗Funktionkeine Funktion
Jedem Argument wird genau ein Funktionswert zugeordnet. Gleiche y-Werte sind erlaubt.

3   Graph

Kreuzen Sie an und begründen Sie mit einem Satz. Das Lineal hilft: senkrecht von links nach rechts schieben.

a)
✗Funktionkeine Funktion
Jedem x-Wert wird genau ein y-Wert zugeordnet.
b)
Funktion✗keine Funktion
Dem Argument x = 0 wird mehr als ein Funktionswert zugeordnet (3 und −3).
c)
✗Funktionkeine Funktion
Jedem x-Wert wird genau ein y-Wert zugeordnet.
Häufige FehlerAufgabe 2c: Alle y-Werte sind gleich – das ist trotzdem eine Funktion. Entscheidend ist nur die obere Zeile.
Aufgabe 3b: Der Kreis wird oft als Funktion angekreuzt, weil er „schön aussieht“. Das Lineal zeigt: bei fast jedem x gibt es zwei Punkte.
