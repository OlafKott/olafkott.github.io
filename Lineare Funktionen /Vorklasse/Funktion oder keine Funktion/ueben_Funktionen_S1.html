Funktion oder keine Funktion?

Was möchtest du üben?

Definition: Funktion

Eine eindeutige Zuordnung ordnet einem beliebigen Wert genau einen anderen Wert zu.
Eine solche Zuordnung nennt man Funktion.

Pfeilbild: Von jedem Element links geht genau ein Pfeil los.
Wertetabelle: Jedem x-Wert (Argument) wird genau ein y-Wert (Funktionswert) zugeordnet.
Graph: Ein senkrechtes Lineal trifft den Graphen an jeder Stelle höchstens einmal.
