1 · Grundverständnis von Funktionsscharen

🟢 🟡 🔴
Übung
1.1… erklären, was eine Funktionsschar ist, und Variable (x) von Parameter (t) unterscheiden.
ft(x) = t·x + 1
Für jedes feste t entsteht eine eigene Gerade.

x = Variable (läuft über den Definitionsbereich).

t = Parameter (ist je Funktion fest und verschiebt/verändert die ganze Kurvenschar).

Der Parameter muss nicht t heißen – auch andere Buchstaben sind üblich, z. B. fa(x)=a·x+1 oder fk(x)=k·x+1.

Übung 1.1
1.2… für einen konkreten Parameterwert die zugehörige Funktion angeben.
ft(x) = x² + t·x
t = 2:  f2(x) = x² + 2x

Den Wert für t einsetzen → konkrete Funktion.

Übung 1.2
1.3… mehrere Kurven einer Schar in ein Koordinatensystem zeichnen.
ft=t·x+1 für t=−1, 1, 2

Für jeden Parameterwert eine Wertetabelle erstellen und die Kurve zeichnen.

Alle Kurven ins selbe Koordinatensystem.

Übung 1.3
2 · Parameter aus Bedingungen bestimmen
Nr.Ich kann …BeispielFormel / Rechenweg
🟢 🟡 🔴
Übung
2.1… den Parameter t so bestimmen, dass der Graph durch einen gegebenen Punkt verläuft – per Hand und mit dem CAS.
ft(x) = t·x + 2,  P(2|8)
2t + 2 = 8 → t = 3,  f3(x) = 3x + 2 ✓
CAS: solve(t·2 + 2 = 8, t) → t = 3
  1. Punkt einsetzen: ft(x₀) = y₀.
  2. nach t auflösen.
  3. Funktion angeben + Probe.

CAS: Mal-Punkt (t·x, nicht tx) und am Ende „, t" angeben.

Übung 2.1
2.2… per Punktprobe entscheiden, welcher von mehreren Graphen zu einer Funktion mit gegebenem Parameter gehört.
Schar: ft(x) = x² + t·x
P(1|3)
▬ f0=x²  ▬ f1=x²+x  ▬ f2=x²+2x

Punktprobe mit P(1|3):

f0(1) = 1 ✗
f1(1) = 1 + 1 = 2 ✗
f2(1) = 1 + 2 = 3 ✓

→ nur f2 verläuft durch P(1|3).
