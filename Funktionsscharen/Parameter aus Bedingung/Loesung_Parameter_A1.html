Parameter aus Bedingungen · Aufgabe 1: Parameter aus einem Punkt
ft(x) = t · x + 2

a) Punkt P(2 | 8)

ft(2) = 8 → t · 2 + 2 = 8 → 2t = 6 → t = 3
f₃(x) = 3x + 2

Probe: 3 · 2 + 2 = 8 ✓

b) Punkt Q(3 | −4)

ft(3) = −4 → t · 3 + 2 = −4 → 3t = −6 → t = −2
f₋₂(x) = −2x + 2

Probe: −2 · 3 + 2 = −4 ✓
