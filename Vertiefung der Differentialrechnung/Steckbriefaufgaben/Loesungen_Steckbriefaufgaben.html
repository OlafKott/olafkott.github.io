Lösungen: Leitbeispiel und Übungsaufgaben
Vertiefung der Differentialrechnung · Steckbriefaufgaben · Lehrertisch
Hinweis
Alle Aufgaben sind so gebaut, dass die Koeffizienten ganzzahlig aufgehen. Zwischenergebnisse mit Brüchen deuten fast immer auf eine falsch übersetzte Bedingung oder einen Einsetzfehler hin.
Die Schüler lösen das Gleichungssystem mit dem CAS. Die hier gezeigten Rechenwege dienen dem Nachvollziehen; bewertet wird das Aufstellen der Bedingungen.
Leitbeispiel: Hochpunkt H(0|4), Wendepunkt W(1|2)
Ansatz:
f(x) = ax³ + bx² + cx + d
f '(x) = 3ax² + 2bx + c,   f ''(x) = 6ax + 2b
Bedingungen:
f(0) = 4  →  d = 4
f '(0) = 0  →  c = 0
f(1) = 2  →  a + b + c + d = 2
f ''(1) = 0  →  6a + 2b = 0
Gleichungssystem und Lösung:
d = 4 und c = 0 einsetzen:   a + b = −2   und   b = −3a
a − 3a = −2  →  a = 1,   b = −3
Ergebnis
f(x) = x³ − 3x² + 4
Probe:
f ''(0) = −6 < 0 → Hochpunkt ✓    f(1) = 1 − 3 + 4 = 2 ✓    f ''(1) = 0, f '''(1) = 6 ≠ 0 → Wendepunkt ✓
Typischer Fehler
„Hochpunkt“ wird nur als Punkt gelesen (eine Gleichung) – die zweite Gleichung f'(0) = 0 fehlt. Dann bleiben drei Gleichungen für vier Unbekannte.
Aufgabe 1: Punkte, Achsen, Nullstelle
Ansatz:
f(x) = ax³ + bx² + cx + d
Bedingungen:
f(0) = 2 → d = 2
f(1) = 0 → a + b + c + 2 = 0
f(−2) = −12 → −8a + 4b − 2c + 2 = −12
f(3) = 8 → 27a + 9b + 3c + 2 = 8
Gleichungssystem und Lösung:
(I) a + b + c = −2
(II) −4a + 2b − c = −7  (durch 2 geteilt)
(III) 9a + 3b + c = 2  (durch 3 geteilt)
(I)+(II): −3a + 3b = −9 → b = a − 3
(III)−(I): 8a + 2b = 4 → 4a + b = 2
4a + a − 3 = 2 → a = 1, b = −2, c = −1
Ergebnis
f(x) = x³ − 2x² − x + 2
Probe:
f(−2) = −8 − 8 + 2 + 2 = −12 ✓   f(3) = 27 − 18 − 3 + 2 = 8 ✓
Typischer Fehler
Vorzeichenfehler beim Einsetzen von x = −2: (−2)³ = −8, aber (−2)² = +4.
Aufgabe 2: Extrempunkt und Wendepunkt
Ansatz:
f(x) = ax³ + bx² + cx + d
f '(x) = 3ax² + 2bx + c,   f ''(x) = 6ax + 2b
Bedingungen:
f(1) = 4 → a + b + c + d = 4
f '(1) = 0 → 3a + 2b + c = 0
f(0) = 2 → d = 2
f ''(0) = 0 → 2b = 0 → b = 0
Gleichungssystem und Lösung:
a + c = 2   und   3a + c = 0
Differenz: 2a = −2 → a = −1, c = 3
Ergebnis
f(x) = −x³ + 3x + 2
Probe:
f ''(x) = −6x,   f ''(1) = −6 < 0 → E ist ein Hochpunkt.   f ''(0) = 0 ✓
Aufgabe 3: Berührpunkt und Steigung
Ansatz:
f(x) = ax³ + bx² + cx + d
f '(x) = 3ax² + 2bx + c,   f ''(x) = 6ax + 2b
Bedingungen:
Ursprung: f(0) = 0 → d = 0
Steigung im Ursprung: f '(0) = 4 → c = 4
berührt x-Achse bei 2: f(2) = 0 → 8a + 4b + 2c = 0  und  f '(2) = 0 → 12a + 4b + c = 0
Gleichungssystem und Lösung:
c = 4 einsetzen:   8a + 4b = −8 → 2a + b = −2;   12a + 4b = −4 → 3a + b = −1
Differenz: a = 1, b = −4
Ergebnis
f(x) = x³ − 4x² + 4x = x(x − 2)²
Probe:
Faktorisierte Form zeigt die doppelte Nullstelle bei 2 → Berührpunkt ✓
Typischer Fehler
„Berührt die x-Achse“ wird als einfache Nullstelle gelesen. Berühren = Nullstelle + waagerechte Tangente (zwei Gleichungen).
Aufgabe 4: Abschnittsweise definierte Funktion
Ansatz:
Gesamtfunktion k aus drei Stücken; gesucht ist das mittlere Stück f(x) = ax³ + bx² + cx + d für 0 < x < 2
links: g(x) = x + 2  (g '(x) = 1)   |   rechts: h(x) = −3x + 10  (h '(x) = −3)
f '(x) = 3ax² + 2bx + c
Bedingungen:
x = 0 ohne Sprung: f(0) = g(0) = 2 → d = 2
x = 0 ohne Knick: f '(0) = g '(0) = 1 → c = 1
x = 2 ohne Sprung: f(2) = h(2) = 4 → 8a + 4b + 2 + 2 = 4
x = 2 ohne Knick: f '(2) = h '(2) = −3 → 12a + 4b + 1 = −3
Gleichungssystem und Lösung:
(I) 8a + 4b = 0  und  (II) 12a + 4b = −4
(II) − (I): 4a = −4 → a = −1,   b = 2
Ergebnis
f(x) = −x³ + 2x² + x + 2   (für 0 < x < 2)
Probe:
f(0) = 2 = g(0) ✓   f '(0) = 1 = g '(0) ✓
f(2) = −8 + 8 + 2 + 2 = 4 = h(2) ✓   f '(2) = −12 + 8 + 1 = −3 = h '(2) ✓
Typischer Fehler
Häufig werden nur zwei Bedingungen gebildet (je Nahtstelle eine), weil „ohne Knick“ als Ersatz für „ohne Sprung“ gelesen wird. Differenzierbarkeit ist aber die zusätzliche Forderung: Pro Nahtstelle gibt es zwei Gleichungen, insgesamt also vier. Zweiter Fehler: h '(2) wird mit h(2) verwechselt – bei einer Geraden ist die Ableitung die Steigung, hier −3.
Aufgabe 5: Sattelpunkt, 4. Grad
Ansatz:
f(x) = ax⁴ + bx³ + cx² + dx + e
f '(x) = 4ax³ + 3bx² + 2cx + d,   f ''(x) = 12ax² + 6bx + 2c
Bedingungen:
f(0) = 0 → e = 0
f(2) = 16 → 16a + 8b + 4c + 2d = 16
f '(2) = 0 → 32a + 12b + 4c + d = 0
f ''(2) = 0 → 48a + 12b + 2c = 0
f(1) = 13 → a + b + c + d = 13
Gleichungssystem und Lösung:
(I) 8a + 4b + 2c + d = 8,   (II) 32a + 12b + 4c + d = 0,   (III) 24a + 6b + c = 0,   (IV) a + b + c + d = 13
(II)−(I): 24a + 8b + 2c = −8 → 12a + 4b + c = −4  (V)
(I)−(IV): 7a + 3b + c = −5  (VI)
(III)−(V): 12a + 2b = 4 → 6a + b = 2;   (V)−(VI): 5a + b = 1
Differenz: a = 1 → b = −4 → (III): c = 0 → (IV): d = 16
Ergebnis
f(x) = x⁴ − 4x³ + 16x
Probe:
f '''(x) = 24x − 24, f '''(2) = 24 ≠ 0 → Sattelpunkt ✓   f(1) = 1 − 4 + 16 = 13 ✓
Typischer Fehler
Sattelpunkt liefert drei Gleichungen (f(2) = 16, f'(2) = 0, f''(2) = 0). Wer nur zwei ansetzt, hat ein unterbestimmtes System. Beim 4×4-Gauß lohnt es sich, zuerst (I) und (IV) zu subtrahieren, weil d dann sofort wegfällt.
Aufgabe 6: Punktsymmetrie und Tiefpunkt
Ansatz:
punktsymmetrisch → nur ungerade Exponenten:   f(x) = ax³ + cx
f '(x) = 3ax² + c
Bedingungen:
f(1) = −2 → a + c = −2
f '(1) = 0 → 3a + c = 0
Gleichungssystem und Lösung:
Differenz: 2a = 2 → a = 1, c = −3
Ergebnis
f(x) = x³ − 3x
Probe:
f ''(x) = 6x, f ''(1) = 6 > 0 → Tiefpunkt ✓
Typischer Fehler
Vollständiger Ansatz mit vier Unbekannten trotz Symmetrie – dann fehlen zwei Gleichungen. Die Symmetrie ist selbst die „Information“, die b = 0 und d = 0 liefert.
Aufgabe 7: Achsensymmetrie, 4. Grad
Ansatz:
achsensymmetrisch → nur gerade Exponenten:   f(x) = ax⁴ + cx² + e
f '(x) = 4ax³ + 2cx
Bedingungen:
f(0) = 2 → e = 2
f(1) = 0 → a + c + 2 = 0
f '(1) = 0 → 4a + 2c = 0 → c = −2a
Gleichungssystem und Lösung:
a − 2a + 2 = 0 → a = 2, c = −4
Ergebnis
f(x) = 2x⁴ − 4x² + 2
Probe:
f ''(x) = 24x² − 8, f ''(1) = 16 > 0 → Tiefpunkt ✓   (auch f(x) = 2(x² − 1)²)
Typischer Fehler
Beim Ansatz wird e vergessen: Die Konstante hat den Exponenten 0 und ist damit „gerade“, sie gehört in den Ansatz.
