Hinweis für den Abgleich
Die Schüler dürfen die Bedingungen auch mit konkreten Bezeichnungen schreiben, z. B. „f(3) = 5“ statt „f(a) = b“. Wichtig ist die Anzahl der Gleichungen je Zeile und die richtige Ableitung: Steigung/Extremum → f', Wendepunkt → f''.

Steigung und Tangente
… hat bei x = a die Steigung m.f '(a) = m
… hat bei x = a eine waagerechte Tangente.f '(a) = 0
… ist bei x = a parallel zur Geraden y = m·x + b.f '(a) = mParallel heißt: gleiche Steigung. Der y-Achsenabschnitt der Geraden spielt keine Rolle.

f '(a) = m		Die Tangente berührt den Graphen: gleicher Funktionswert und gleiche Steigung an der Stelle a.

f '(a) = 0		Ein Punkt liefert immer eine Gleichung, die Eigenschaft „Extremum“ eine zweite.

Nahtstellen (abschnittsweise definierte Funktionen)
… geht bei x = a ohne Sprung in g über.
… ist bei x = a stetig.		f(a) = g(a)Stetig heißt: Beide Teilfunktionen haben an der Nahtstelle denselben Funktionswert.

f '(a) = g '(a)		Differenzierbar schließt stetig mit ein: gleicher Funktionswert und gleiche Steigung. Zwei Gleichungen!

… ist achsensymmetrisch zur y-Achse.nur gerade ExponentenBeispiel Grad 4: f(x) = ax⁴ + cx² + e. Es bleiben nur 3 Unbekannte.
Typischer Fehler
Zwei-Gleichungen-Zeilen werden gern halb übersetzt: Beim Extrempunkt E(a|b) wird nur f'(a) = 0 notiert und f(a) = b vergessen (oder umgekehrt). Beim Berührpunkt mit der x-Achse fehlt meist die waagerechte Tangente. Beim Sattelpunkt fehlt oft die dritte Gleichung. Nachzählen lassen: Anzahl der Gleichungen = Anzahl der Unbekannten?
