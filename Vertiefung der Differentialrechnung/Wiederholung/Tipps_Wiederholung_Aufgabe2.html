Aufgabe
f(x) = −x + 1für x < −1 0,5x²für −1 ≤ x ≤ 2 −0,5x + 3für x > 2
Tipp 1zu a)

Welcher Abschnitt gilt?

Die Bedingungen rechts teilen den Zahlenstrahl in drei Bereiche. Bevor du rechnest, suchst du deine Stelle x auf dem Zahlenstrahl und liest ab, welche Farbe – also welche Teilfunktion – dort gilt.

Entscheidend sind die Randstellen −1 und 2. Die Zeichen ≤ und ≥ bedeuten „gehört dazu“, < und > bedeuten „gehört nicht dazu“. Beide Randstellen stehen hier mit ≤ im mittleren Abschnitt.

Tipp 2zu a)

Einsetzen nur in diese eine Teilfunktion

Hast du den Abschnitt gefunden, setzt du nur in diese Teilfunktion ein – die beiden anderen ignorierst du komplett.

Beispiel mit einer anderen Funktion
g(x) = x + 2 für x < 0;   x² für 0 ≤ x ≤ 1;   3 − x für x > 1
g(−1):  −1 < 0 → erster Abschnitt → g(−1) = −1 + 2 = 1
g(0):    0 liegt in 0 ≤ x ≤ 1 → mittlerer Abschnitt → g(0) = 0² = 0
g(1):    1 liegt in 0 ≤ x ≤ 1 → mittlerer Abschnitt → g(1) = 1² = 1
g(2):    2 > 1 → dritter Abschnitt → g(2) = 3 − 2 = 1
Vorzeichen: Bei −x + 1 und x = −3 wird aus −x der Wert −(−3) = +3. Und 0,5x² mit x = −1 ergibt 0,5·(−1)² = 0,5·1 – das Quadrat macht das Minus weg.
Tipp 3zu b)

So zeichnest du den Graphen

Jede Teilfunktion wird nur in ihrem Bereich gezeichnet. Für die beiden Geraden reichen zwei Punkte, für die Parabel nimmst du deine vier Tabellenwerte. Damit der Graph den ganzen Bereich von −4 bis 6 füllt, rechne zusätzlich noch f(−4) und f(6) aus.

An den Nahtstellen fragst du: Was würde der andere Ast an dieser Stelle liefern? Diesen Wert markierst du mit einem leeren Kreis, weil er nicht dazugehört. Den Wert aus der Wertetabelle setzt du als ausgefüllten Punkt.

Im Beispiel rechts: Bei x = 0 würde der linke Ast 2 liefern → leerer Kreis bei (0 | 2), ausgefüllter Punkt bei (0 | 0). Bei x = 1 würde der rechte Ast 2 liefern → leerer Kreis bei (1 | 2), ausgefüllter Punkt bei (1 | 1).

Beispielfunktion g
Und wenn beide Äste denselben Wert liefern? Dann treffen sie sich in einem Punkt – es gibt keinen Sprung und du brauchst nur einen ausgefüllten Punkt. Prüfe das an beiden Nahtstellen deiner Funktion, das Ergebnis ist nicht an beiden gleich.
