Zusammenfassung – Betriebsminimum und Betriebsoptimum

Ökonomische Anwendungen · Preisuntergrenzen im Polypol
Fixkosten
Kfix = K(0)
variable Kosten
Kv(x) = K(x) − Kfix
variable Stückkosten
kv(x) = Kv(x)x
Stückkosten
k(x) = K(x)x
Grenzkosten
K′(x)

Beispiel aus der Präsentation:

K(x) = x³ − 12x² + 60x + 98
1  Im Graphen bestimmen

BO: Drehe eine Gerade durch den Ursprung nach unten, bis sie K nur noch berührt.
LPU = Steigung = Kosten : Menge = 273 : 7 = 39

BM: Drehe eine Gerade durch den Punkt (0 | Kfix), bis sie K nur noch berührt.
KPU = Steigung = (Kosten − Fixkosten) : Menge = (242 − 98) : 6 = 24

Das BM ist der Tiefpunkt von kv. Das BO ist der Tiefpunkt von k.

Die Grenzkostenkurve K′ schneidet kv und k genau in diesen Tiefpunkten.

2  Berechnen
Betriebsminimum und KPU
  1. kv(x) aufstellen:  kv(x) = x² − 12x + 60
  2. Notwendige Bedingung: kv′(x) = 0
    2x − 12 = 0  ⇒  x = 6
  3. Hinreichende Bedingung: kv″(x) > 0
    kv″(6) = 2 > 0  ⇒  Tiefpunkt
  4. KPU = kv(6) = 36 − 72 + 60 = 24
BM (6 | 24)  ·  KPU = 24 GE/ME
Anderer Weg: kv(x) = K′(x) gleichsetzen (pq-Formel oder CAS).
Betriebsoptimum und LPU
  1. k(x) aufstellen:  k(x) = x² − 12x + 60 + 98x
  2. Notwendige Bedingung: k′(x) = 0
    2x − 12 − 98x² = 0  ⇒  x = 7
    CAS: solve(2x−12−98/x^2=0, x) oder Horner-Schema
  3. Hinreichende Bedingung: k″(x) > 0
    k″(7) = 2 + 196343 ≈ 2,57 > 0  ⇒  Tiefpunkt
  4. LPU = k(7) = 49 − 84 + 60 + 14 = 39
BO (7 | 39)  ·  LPU = 39 GE/ME
Anderer Weg: k(x) = K′(x) gleichsetzen (Horner-Schema oder CAS).
