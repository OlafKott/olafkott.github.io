1.1… bei einer abschnittsweise definierten Funktion prüfen, ob sie an der Nahtstelle stetig ist.
f(x) =
x² + 1für x ≤ 2
3x − 1für x > 2
f1(2) = 4 + 1 = 5
f2(2) = 6 − 1 = 5
5 = 5  →  stetig
Beide Teilfunktionen an der Nahtstelle x0 einsetzen:
f1(x0) = f2(x0)
Gleich → stetig: Der Graph hat keinen Sprung.
Verschieden → nicht stetig.
Übung 1.1
1.2… prüfen, ob eine Funktion an der Nahtstelle differenzierbar ist.
Funktion aus 1.1 ist stetig.
f1'(x) = 2x → f1'(2) = 4
f2'(x) = 3 → f2'(2) = 3
4 ≠ 3 → nicht differenzierbar (Knick)
Zwei Bedingungen prüfen:
① f1(x0) = f2(x0)
② f1'(x0) = f2'(x0)
Beide erfüllt → differenzierbar: kein Sprung und kein Knick.
Ohne Stetigkeit keine Differenzierbarkeit!

3. Trassierung
Nr.Ich kann …BeispielFormel / RechenwegAmpelÜbung
3.1… die Übergangsbedingungen an einer Nahtstelle x0 zwischen zwei Abschnitten f und g aufstellen.
ÜbergangBedingung
sprungfrei (keine Lücke)f(x0) = g(x0)
knickfrei (gleiche Steigung)f'(x0) = g'(x0)
krümmungsruckfrei (gleiche Krümmung)f''(x0) = g''(x0)
Jede Nahtstelle liefert Bedingungen:
• sprung- und knickfrei: 2 Bedingungen
• zusätzlich krümmungsruckfrei: 3 Bedingungen
Die Werte der gegebenen Abschnitte (f, f', f'') an der Nahtstelle zuerst berechnen.
Übung 3.1
3.2… zwei gegebene Abschnitte durch ein sprung-, knick- und krümmungsruckfreies Verbindungsstück verbinden.
f1(x) = 0,5x + 1,5  (x ≤ 0),  f2(x) = 3,5  (x ≥ 2)
Verbindung p für 0 < x < 2, Ansatz 5. Grades:
p(x) = ax⁵ + bx⁴ + cx³ + dx² + ex + f
p(0) = 1,5,  p'(0) = 0,5,  p''(0) = 0
p(2) = 3,5,  p'(2) = 0,  p''(2) = 0
→ (CAS)  p(x) = 932x⁵ − 118x⁴ + 74x³ + 0,5x + 1,5
2 Nahtstellen × 3 Bedingungen = 6 Bedingungen → Ansatz 5. Grades (6 Unbekannte).
Rechte Seiten aus den gegebenen Abschnitten:
f1(0) = 1,5,  f1'(0) = 0,5,  f1''(0) = 0
f2(2) = 3,5,  f2'(2) = 0,  f2''(2) = 0
Bei Geraden und Konstanten ist die 2. Ableitung immer 0.
Das Gleichungssystem löst du mit dem CAS.
Übung 3.2

Figur / KörperFläche bzw. VolumenUmfang bzw. Oberfläche
RechteckA = a · bU = 2a + 2b

Diese Formeln brauchst du für die Hauptbedingung und oft auch für die Nebenbedingung.

Achte auf den Sachzusammenhang:
• Ohne Deckel (offene Schachtel, Dose): eine Fläche fällt weg.
• An einer Wand / Mauer: dort wird kein Zaun gebraucht.
• Zylinder-Mantel: 2πrh, Kegel-Mantel: πrs (s = Mantellinie).

4. Extremwertaufgaben mit Randprüfung (Fortsetzung)
Leitbeispiel für 4.2 – 4.5: Mit 50 m Zaun soll an einer 20 m langen Mauer ein rechteckiges Gehege gebaut werden. Die Mauer soll ganz genutzt werden. Wie groß muss das Gehege sein, damit die Fläche möglichst groß wird?

4.2… zu einer Extremwertaufgabe eine Skizze, die Hauptbedingung und die Nebenbedingung aufstellen und daraus die Zielfunktion bilden.0 Skizze:
1 Amax   2 HB: A = a · h
3 NB: 50 = a + 2h + (a − 20)
4 h = 35 − a
5 A(a) = a · (35 − a)
0 Skizze mit allen Größen

Übung 4.2
4.3… die Extremstelle der Zielfunktion berechnen und prüfen, ob ein Maximum bzw. Minimum vorliegt.
6 A(a) = 35a − a²,  A'(a) = 35 − 2a
7 35 − 2a = 0 → a = 17,5
10 A''(a) = −2 < 0 → lokales Maximum
Aber: Ist a = 17,5 überhaupt möglich? → 4.4
6 Zielfunktion vereinfachen und ableiten
7 Ableitung = 0 setzen → Extremstelle
10 hinreichende Bedingung prüfen:
   Z''(x) < 0 → Maximum, Z''(x) > 0 → Minimum
Übung 4.3
4.4… den Definitionsbereich der Zielfunktion aus dem Sachzusammenhang festlegen.
Die Mauer soll ganz genutzt werden:  a ≥ 20
Die Tiefe darf nicht negativ sein:  h = 35 − a ≥ 0 → a ≤ 35
→ D = [20; 35]
a = 17,5 liegt nicht in D!
Frage dich: Welche Werte sind im Sachzusammenhang möglich?
• Längen sind nicht negativ.
• Vorgaben aus dem Text (Mauerlänge, Materialmenge, Platz) begrenzen die Werte.
Die Grenzen von D sind die Ränder.
Übung 4.4
4.5… eine Randprüfung durchführen, das Ergebnis bestimmen und einen Antwortsatz formulieren.
Ränder: A(20) = 300,  A(35) = 0
→ Maximum am Rand a = 20
8 h = 35 − 20 = 15
9 A = 20 · 15 = 300
Das Gehege wird 20 m breit und 15 m tief; die Fläche beträgt 300 m².
1. Liegt die Extremstelle in D?
2. Funktionswerte an der Extremstelle (falls in D) und an beiden Rändern berechnen.
3. Der größte (kleinste) Wert ist das gesuchte Maximum (Minimum).

9 beide Größen in die HB einsetzen
