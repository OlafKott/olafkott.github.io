Vom Term zum Graphen · Aufgabe 7: Quadratischen Abschnitt bestimmen

a) Linearer Abschnitt

Gerade durch (−2 | 2) und (0 | −2): m = (−2−2)/(0−(−2)) = −2, b = −2 → y = −2x − 2.

b) Quadratischer Abschnitt – Weg 1: Gauß / LGS

Ansatz y = a·x² + b·x + c durch P₁(1|1), P₂(2|2), P₃(4|−2):

(I)   a + b + c = 1
(II)   4a + 2b + c = 2
(III) 16a + 4b + c = −2
(II)−(I): 3a + b = 1  ·  (III)−(II): 12a + 2b = −4 → 6a + b = −2
Differenz: 3a = −3 → a = −1,   b = 4,   c = −2

b) Weg 2: Scheitelpunktform

Scheitel S(2 | 2) ablesen → y = a·(x − 2)² + 2; durch P₃(4 | −2): −2 = a·4 + 2 → a = −1.

y = −(x − 2)² + 2 = −x² + 4x − 2
Quadratischer Abschnitt:   y = −x² + 4x − 2
