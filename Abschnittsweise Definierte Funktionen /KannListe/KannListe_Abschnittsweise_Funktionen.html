Übung
1.1… erklären, was eine abschnittsweise definierte Funktion ist, und die Schreibweise mit geschweifter Klammer lesen.
Handytarif (12 € Grundgeb., 3 GB frei, dann 1,50 €/GB):
K(x) ={
12für 0 ≤ x ≤ 3
1,5x + 7,5für x > 3

Eine Funktion, die auf verschiedenen Bereichen durch verschiedene Teilfunktionen beschrieben wird (Fallunterscheidung).

Die geschweifte Klammer fasst die Teilfunktionen mit ihren Bereichen zusammen.

Übung 1.1
1.2… zu einem gegebenen x den richtigen Bereich bestimmen und den Funktionswert berechnen.
f(x) ={
x + 2für x ≤ 1
2xfür x > 1
f(1) = 1 + 2 = 3  (da 1 ≤ 1)
f(2) = 2·2 = 4  (da 2 > 1)
  1. Prüfen, in welchem Bereich x liegt.
  2. Dort die passende Teilfunktion einsetzen.

An den Grenzen genau auf ≤ und < achten.

Übung 1.2
1.3… den Graphen mithilfe einer Wertetabelle zeichnen und die Randpunkte (● / ○) richtig setzen.
p(x) ={
2für −3 ≤ x ≤ 0
x − 1für 0 < x ≤ 4
x−2−10124
p(x)222013

Für jeden Abschnitt nur x-Werte aus seinem Bereich in die Wertetabelle einsetzen und den Teilgraphen nur über seinem Bereich zeichnen.

● geschlossener Punkt: Randwert gehört dazu (≤, ≥).
○ offener Punkt: gehört nicht dazu (<, >).

Übung 1.3
1.4… zu einem gegebenen Graphen die vollständige abschnittsweise Funktion mit geschweifter Klammer angeben.
Beispiel mit Sprung bei x = 0
g(x) ={
−2x − 2für −2 ≤ x ≤ 0
−x² + 4x + 1für 0 < x ≤ 4

Für jeden Abschnitt Bereich und Funktionstyp bestimmen:

konstant → y = c;  linear → y = m·x + b;  quadratisch → Scheitelpunktform oder 3 Punkte (Gauß / CAS).

An einer Sprungstelle die Randpunkte (● / ○) entsprechend setzen, dann mit geschweifter Klammer zusammenfassen.
