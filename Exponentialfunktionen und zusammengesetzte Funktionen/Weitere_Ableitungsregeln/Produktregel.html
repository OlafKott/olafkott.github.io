1Darf man Faktoren einzeln ableiten?

f(x) = x² · x³
Vermutung: Jeden Faktor ableiten und malnehmen:
2x · 3x² = 6x³
Kontrolle: x² · x³ = x⁵. Mit der Potenzregel gilt f′(x) = 5x⁴.
6x³ ≠ 5x⁴  – die Vermutung ist falsch! Für Produkte brauchen wir eine eigene Regel.

2Die Produktregel

Satz: Produktregel

Ist f(x) = u(x) · v(x), dann gilt:
f′(x) = u′(x) · v(x) + u(x) · v′(x)
„Ableitung der ersten mal die zweite plus die erste mal Ableitung der zweiten“
Es wird also immer nur ein Faktor abgeleitet – erst der erste, dann der zweite.

✎Jetzt du: Stimmt die Regel?

Prüfe die Produktregel an f(x) = x² · x³.
u′ · v = 2x · x³ = x⁴
u · v′ = x² · 3x² = x⁴
f′(x) = x⁴
So ist es richtig:
2x⁴ + 3x⁴ = 5x⁴. Das stimmt mit der Potenzregel überein: (x⁵)′ = 5x⁴ ✔
Die Produktregel liefert dasselbe Ergebnis wie das Ausmultiplizieren. 👍

Die e-Funktion steht in beiden Summanden. Darum kann man sie ausklammern.

4Die zweite Ableitung

f′(x) = (−x + 0,5) · e−0,5x
Auch f′ ist ein Produkt. Wende die Produktregel noch einmal an.
u = −x + 0,5   v = e−0,5x    u′ = −1   v′ = −0,5e−0,5x
f″(x)=(−1) · e−0,5x + (−x + 0,5) · (−0,5e−0,5x)=e−0,5x · (−1 + 0,5x − 0,25)=e−0,5x · (0,5x − 1,25)

4Extrempunkt mit der Produktregel

f(x) = (2x + 3) · e−0,5x
1. f′(x) = e−0,5x · (−x + 0,5) = 0
2. e−0,5x wird nie 0. Ein Produkt ist 0, wenn ein Faktor 0 ist. Also muss die Klammer 0 sein:
−x + 0,5=0| + xx=0,5
3. f(0,5) = 4 · e−0,25 ≈ 3,12
4. f″(0,5) = e−0,25 · (−1) < 0  ⟹  Hochpunkt
Hochpunkt H(0,5 | 3,12)

?Frage

Warum reicht es bei e−0,5x · (−x + 0,5) = 0, nur die Klammer gleich 0 zu setzen?
AWeil die e-Funktion nie 0 wird.
BWeil die e-Funktion immer 1 ist.
CWeil man e-Funktionen beim Lösen immer weglassen darf.
So ist es richtig:
e-Potenzen sind immer größer als 0. Ein Produkt ist nur 0, wenn ein Faktor 0 ist. Also muss die Klammer 0 sein. Darum lohnt sich das Ausklammern!

★Zusatz für Interessierte: Die Quotientenregel freiwillig

Quotientenregel

f(x) = uv  ⟹  f′(x) = u′ · v − u · v′v²
Merkspruch: „NAZ minus ZAN durch N²“
Warum du sie eigentlich nicht brauchst:
Durch v teilen ist dasselbe wie mit v−1 malnehmen: uv = u · v−1
Mit Produktregel und Kettenregel kommt genau die Quotientenregel heraus. Sie ist nur eine Abkürzung.
Bei der e-Funktion ist es noch einfacher: 1ex = e−x
f(x)=x + 2ex = (x + 2) · e−xf′(x)=1 · e−x + (x + 2) · (−e−x)=e−x · (−x − 1)
