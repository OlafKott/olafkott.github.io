↺Rückblick: Warum eigentlich die e-Funktion?

Bei der natürlichen Exponentialfunktion hast du jede Exponentialfunktion in eine e-Funktion umgewandelt:
vorher
f(x) = c · ax
⟶
nachher
f(x) = c · eln(a) · x
Zum Beispiel: f(x) = 3,125 · 0,8x ≈ 3,125 · e−0,2231x
Wir hatten gesagt: Mit der e-Funktion wird das Ableiten später viel einfacher.
Jetzt kommt die Aufklärung, warum das so ist.
Dazu schauen wir uns den Graphen von ex genau an.

Merke

f(x) = ex  ⟹  f′(x) = ex
Die e-Funktion ist ihre eigene Ableitung.
Faktorregel: Der Faktor bleibt stehen.
f(x) = 4ex  ⟹  f′(x) = 4ex
Summenregel: Summand für Summand.
f(x) = ex + x²  ⟹  f′(x) = ex + 2x
Achtung: e ≈ 2,718 ist eine Zahl.
f(x) = e³ + 2x  ⟹  f′(x) = 2

2Beispiel: Schritt für Schritt

f(x) = 3ex − 2x² + 5
1
Summanden trennen
3ex   − 2x²   + 5
2
Jeden Summanden einzeln ableiten
3ex ⟶ 3ex   − 2x² ⟶ − 4x   + 5 ⟶ 0
3
Zusammensetzen
f′(x) = 3ex − 4x

!Typische Fallen

f(x) = ex + 3
❌ f′(x) = ex + 3    ✔ f′(x) = ex  – die Konstante 3 fällt weg.
f(x) = e³
❌ f′(x) = 3e²    ✔ f′(x) = 0  – e³ ≈ 20,09 ist nur eine Zahl ohne x.
f(x) = ex
❌ f′(x) = x · ex − 1    ✔ f′(x) = ex  – die Potenzregel gilt nur, wenn x unten steht.
Frage dich immer: Steht x im Exponenten oder in der Basis?

?Frage

Wie lautet die Ableitung von f(x) = −2ex + x³?
Af′(x) = −2ex + 3x²
Bf′(x) = −2x · ex − 1 + 3x²
Cf′(x) = ex + 3x²
Df′(x) = −2ex + x³
So ist es richtig:
−2ex ⟶ −2ex (Faktor bleibt) und x³ ⟶ 3x².

?Frage: Vorsicht, Falle!

Wie lautet die Ableitung von f(x) = e² + 4ex?
Af′(x) = 4ex
Bf′(x) = 2e + 4ex
Cf′(x) = e² + 4ex
Df′(x) = 4x · ex − 1
So ist es richtig:
e² ≈ 7,39 ist eine Konstante und fällt weg. 4ex bleibt 4ex.
