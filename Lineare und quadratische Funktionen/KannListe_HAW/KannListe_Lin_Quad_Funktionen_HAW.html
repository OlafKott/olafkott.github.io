4.1… eine quadratische Funktion aufstellen. Schritt 1: Ansatz wählen und aus drei Punkten die Bedingungen und das LGS aufstellen.
P₁(1 | 2), P₂(2 | 3), P₃(−1 | 6)
Ansatz: f(x) = ax² + bx + c
P1(1 | 2) ⇒ f(1) = 2 ⇒
a · 1² + b · 1 + c=2
a + b + c=2(I)
P2(2 | 3) ⇒ f(2) = 3 ⇒
a · 2² + b · 2 + c=3
4a + 2b + c=3(II)
P3(−1 | 6) ⇒ f(−1) = 6 ⇒
a · (−1)² + b · (−1) + c=6
a − b + c=6(III)
f(x) = ax² + bx + c

Aus P(x | y) folgt f(x) = y ⇒ a · x² + b · x + c = y.

Darunter vereinfachen. Drei Punkte ergeben drei Gleichungen I, II, III.

(−2)² = 4 ist positiv. Liegt ein Punkt auf der y-Achse, kommt er in Zeile III.

Erlös: E(x) = p · x
E(x) = 6x
Gerade durch den Ursprung, Steigung = Preis 6 GE/ME
Kosten: K(x) = Kvar(x) + Kfix
K(x) = 2x + 16
Kvar(x) = 2x: Steigung = variable Kosten 2 GE/ME, Kfix = 16 GE
Gewinn: G(x) = E(x) − K(x)
G(x) = 4x − 16
beginnt bei den negativen Fixkosten
Ich kann … die Situation im Polypol beschreiben und berechnen (Erlös, Kosten, Gewinn, BEP, Zonen, Gewinnmaximum).
→ Übung 5 (QR-Code)
Marktform Polypol
Viele Anbieter, viele Käufer. Der Preis ist fest: Die Firma ist Mengenanpasser.
So wird gerechnet
1. Gewinnfunktion aufstellen
G(x)=E(x) − K(x)
=6x − (2x + 16)
=6x − 2x − 16
=4x − 16
2. Gewinnschwelle: G(x) = 0
4x − 16=0| + 16
4x=16| : 4
x=4
⇒ xGS = 4
3. Break-Even-Point: E(x) = K(x)
6x=2x + 16| − 2x
4x=16| : 4
xGS=4
E(4)=6 · 4 = 24
⇒ BEP(4 | 24)
Definitionsbereich und Zonen
Dök = [0 ; 10]  (bis zur Kapazitätsgrenze)
Verlustzone = [0 ; xGS[ = [0 ; 4[   Gewinnzone = ]4 ; 10]
Quadratische Kosten: K(x) = ax² + bx + c
progressiv: a > 0
K steigt immer schneller. E und K schneiden sich zweimal: Verlust, Gewinn, wieder Verlust.
degressiv: a < 0
K steigt immer langsamer. Nach dem BEP bleibt die Firma in der Gewinnzone.

pN(x) = −2x + 32
fällt, y-Achsenabschnitt = Höchstpreis
Erlös: E(x) = pN(x) · x
E(x) = −2x² + 32x

Kosten
K(x) = 8x + 40
beginnt bei den Fixkosten
Gewinn: G(x) = E(x) − K(x)
G(x) = −2x² + 24x − 40

Ich kann … Preis-Absatz-Funktion, Erlös, Gewinn und Cournot-Punkt im Monopol bestimmen.
→ Übung 7 (QR-Code)
Marktform Monopol
Nur ein Anbieter. Die Firma ist Preisfestsetzer: Will sie mehr verkaufen, muss sie den Preis senken.
So wird gerechnet
1. Erlös- und Gewinnfunktion
E(x)=pN(x) · x = (−2x + 32) · x = −2x² + 32x
G(x)=E(x) − K(x) = −2x² + 32x − (8x + 40)
=−2x² + 32x − 8x − 40
=−2x² + 24x − 40
2. Gewinnschwelle und Gewinngrenze: G(x) = 0
−2x² + 24x − 40=0| : (−2)
x² − 12x + 20=0
pq-Formel oder CAS solve(g(x)=0,x) ⇒ xGS = 2, xGG = 10
3. Gewinnmaximum und Cournot-Punkt
xS=(2 + 10) : 2 = 6
G(6)=−2 · 6² + 24 · 6 − 40 = 32
pN(6)=−2 · 6 + 32 = 20
⇒ C(6 | 20)
Bedeutung und Zonen
Cournot-Punkt: Bei 6 ME und einem Preis von 20 GE/ME macht der Monopolist den größten Gewinn. C liegt auf pN, nicht auf G.
Dök = [0 ; 16]  (bis zur Sättigungsmenge)
Gewinnzone = ]2 ; 10[   Verlustzone = [0 ; 2[ und ]10 ; 16]
