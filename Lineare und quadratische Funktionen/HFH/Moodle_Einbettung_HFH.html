Moodle-Einbettung: HFH Lineare Funktionen

Ein Code pro Übersicht. Die Höhe passt sich automatisch an die Bildschirmbreite an.

So geht es: Im Moodle-Editor (Textfeld oder Textseite) auf HTML-Ansicht (</>) umschalten, den Code einfügen, speichern.
Das Script im Code passt die Höhe an. Falls Moodle das Script entfernt, bleibt die Startgröße stehen. Dann im style die Zahl bei height anpassen.

Materialübersicht: Lineare Funktionen (HFH)

Seite öffnen ↗

<div style="width:100%;max-width:800px;margin:0 auto;">
<iframe id="hfh-mat" src="https://olafkott.github.io/Lineare%20und%20quadratische%20Funktionen/HFH/Materialuebersicht_HFH.html" title="Materialübersicht: Lineare Funktionen (HFH)" loading="lazy" scrolling="no" style="display:block;width:100%;height:820px;border:0;overflow:hidden;"></iframe>
</div>
<script>
(function(){
  var f = document.getElementById("hfh-mat");
  window.addEventListener("message", function(e){
    if (!f || e.source !== f.contentWindow || !e.data || !e.data.grundlagenHeight) return;
    f.style.height = (e.data.grundlagenHeight + 2) + "px";
  });
})();
</script>
