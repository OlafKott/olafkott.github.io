Quadratische Funktion durch P1(0|1), P2(1|2), P3(2|7)
Ansatz: f(x) = ax² + bx + c
P1: 0a + 0b + c = 1
P2: 1a + 1b + c = 2
P3: 4a + 2b + c = 7
→ Lösung in 1.2.
  1. Ansatz der Funktion wählen (Grad festlegen).
  2. Jeden Punkt einsetzen → eine Gleichung pro Punkt.
  3. LGS aufstellen und lösen.
  4. Lösungen in den Funktionsterm einsetzen.

Anzahl der Gleichungen muss zur Anzahl der Unbekannten passen.

Die letzte Zeile (oder die unteren Nullzeilen) der Stufenform entscheiden:

  1. Form 0 = c mit c ≠ 0 → keine Lösung.
  2. Form 0 = 0 → mindestens eine freie Variable → unendlich viele Lösungen.

Anzahl freier Variablen = Anzahl Variablen − Anzahl führender Zahlen.

Konvention: Eintrag rzi,j = ME von Ri für 1 ME von Zj.

4.1 … die Eigenschaften einer stochastischen Matrix prüfen (quadratisch, Einträge in [0; 1], Spaltensumme 1).
M =
0,70,2
0,30,8
• quadratisch (2×2) ✓
• alle Einträge in [0; 1] ✓
• Spalte 1: 0,7 + 0,3 = 1 ✓
• Spalte 2: 0,2 + 0,8 = 1 ✓
→ stochastische Matrix

Drei Bedingungen einzeln prüfen:

  1. Matrix ist quadratisch.
  2. Alle Einträge liegen in [0; 1].
  3. Jede Spaltensumme = 1.

Wenn eine Bedingung verletzt ist, dann ist die Matrix nicht stochastisch.
