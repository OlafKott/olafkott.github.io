ÜBUNG 4.7 · MONOPOL

Cournot-Punkt bestimmen

Bestimme die gewinnmaximale Menge, den zugehörigen Preis und damit den Cournot-Punkt.

Aufgabenstellung
Der Cournot-Punkt C(xC | pC) ist der Punkt auf der PAF, der dem Gewinnmaximum eines Monopolisten entspricht. xC = gewinnmaximale Menge; pC = p(xC).
Hilfsmittel: Diese Aufgabe kannst du sowohl oHiMi als auch mit dem CAS lösen.
a)
Gegeben: K(x) = x³ − 9x² + 30x + 100;   p(x) = −x + 42.
Bestimme den Cournot-Punkt und den maximalen Gewinn.
b)
Gegeben: K(x) = x³ − 6x² + 15x + 20;   p(x) = −x + 20 (vgl. Übung 4.4).
Bestimme den Cournot-Punkt mit dem CAS.
c) — Anwendung
Ein regionaler Wasserversorger ist Monopolist. Die Kostenfunktion lautet K(x) = 0,5x³ − 6x² + 30x + 200 (x in 1000 m³, K in 100 €). Die Preis-Absatz-Funktion ist p(x) = −0,5x + 20 (Preis in € pro m³).
Bestimme den Cournot-Punkt und interpretiere ihn im Sachzusammenhang.
Lösungen
a) K(x) = x³ − 9x² + 30x + 100; p(x) = −x + 42
E(x) = (−x + 42)·x = −x² + 42x
G(x) = E − K = −x² + 42x − x³ + 9x² − 30x − 100 = −x³ + 8x² + 12x − 100
G′(x) = −3x² + 16x + 12;   G″(x) = −6x + 16

G′(x) = 0:   x1,2 = (16 ± √(256 + 144))/6 = (16 ± 20)/6
x1 = −2/3 (unzulässig);   xC = 6
G″(6) = −20 < 0 → Maximum ✓

Cournot-Preis: pC = p(6) = −6 + 42 = 36
Cournot-Punkt: C(6 | 36)
Maximaler Gewinn: G(6) = −216 + 288 + 72 − 100 = 44 GE
b) K(x) = x³ − 6x² + 15x + 20; p(x) = −x + 20
E(x) = −x² + 20x;   G(x) = −x³ + 5x² + 5x − 20
G′(x) = −3x² + 10x + 5 = 0 → x1,2 = (10 ± √(100 + 60))/6 = (10 ± √160)/6
√160 ≈ 12,65 → x1 ≈ −0,44 (unzulässig);   xC ≈ 3,77
G″(xC) ≈ −22,6 < 0 ✓

Cournot-Preis: pC = p(3,77) ≈ 16,23
Cournot-Punkt: C(3,77 | 16,23)
Hier liefert das CAS exakte Werte; die Lösung ist nicht ganzzahlig.
c) Wasserversorger: K(x) = 0,5x³ − 6x² + 30x + 200; p(x) = −0,5x + 20
E(x) = −0,5x² + 20x
G(x) = −0,5x² + 20x − 0,5x³ + 6x² − 30x − 200 = −0,5x³ + 5,5x² − 10x − 200
G′(x) = −1,5x² + 11x − 10;   G″(x) = −3x + 11

G′(x) = 0:   1,5x² − 11x + 10 = 0 → x² − (22/3)x + 20/3 = 0
Mit dem CAS: x1 = 1;   xC ≈ 6,33
G″(6,33) ≈ −8 < 0 ✓

Cournot-Preis: pC = p(6,33) = −3,17 + 20 ≈ 16,83
Cournot-Punkt: C(6,33 | 16,83)
Interpretation: Der Wasserversorger erzielt seinen maximalen Gewinn, wenn er ca. 6 330 m³ Wasser zum Preis von ca. 16,83 € pro m³ anbietet. Eine größere Menge zum geringeren Preis oder eine kleinere Menge zum höheren Preis würden beide den Gewinn schmälern.
Cournot-Punkt: Schritte: (1) G(x) bilden, (2) G′(x) = 0 → xC, (3) G″(xC) < 0 prüfen, (4) pC = p(xC), (5) C(xC | pC).
