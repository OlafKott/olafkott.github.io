ÜBUNG 4.6 · MONOPOL

Gewinnmaximum bestimmen

Bestimme die gewinnmaximale Menge x* und den maximalen Gewinn G(x*).

Aufgabenstellung
Bestimme jeweils die gewinnmaximale Menge x* (Cournot-Menge) und den maximalen Gewinn G(x*). Notwendige Bedingung: G′(x) = 0; hinreichend: G″(x) < 0.
Hilfsmittel: Diese Aufgabe kannst du sowohl oHiMi als auch mit dem CAS lösen.
a)
G(x) = −x³ + 6x² − 9x + 4
b)
G(x) = −x³ + 8x² + 12x − 100
c) — Anwendung
Ein Möbelhersteller produziert eine Spezialcouch. Gegeben sind die Kostenfunktion K(x) = x³ − 12x² + 60x + 200 und die PAF p(x) = −2x + 80 (x in Stück, Preise und Kosten in €).
Berechne die gewinnmaximale Menge x* und den maximalen Gewinn G(x*).
Lösungen
a) G(x) = −x³ + 6x² − 9x + 4
G′(x) = −3x² + 12x − 9 = −3(x² − 4x + 3) = −3(x − 1)(x − 3)
G″(x) = −6x + 12

G′(x) = 0:   x1 = 1;   x2 = 3
G″(1) = 6 > 0 → Minimum bei x = 1 (uninteressant)
G″(3) = −6 < 0 → Maximum bei x* = 3
G(3) = −27 + 54 − 27 + 4 = 4
→ Gewinnmaximum bei x* = 3 mit G(3) = 4 GE
b) G(x) = −x³ + 8x² + 12x − 100
G′(x) = −3x² + 16x + 12
G″(x) = −6x + 16

G′(x) = 0:   x1,2 = (16 ± √(256 + 144)) / 6 = (16 ± 20) / 6
x1 = −2/3 (negativ → unzulässig);   x2 = 6
G″(6) = −20 < 0 → Maximum
G(6) = −216 + 288 + 72 − 100 = 44
→ Gewinnmaximum bei x* = 6 mit G(6) = 44 GE
c) Möbelhersteller: K(x) = x³ − 12x² + 60x + 200; p(x) = −2x + 80
E(x) = p(x)·x = (−2x + 80)·x = −2x² + 80x
G(x) = E(x) − K(x) = −2x² + 80x − x³ + 12x² − 60x − 200
G(x) = −x³ + 10x² + 20x − 200
G′(x) = −3x² + 20x + 20;   G″(x) = −6x + 20

G′(x) = 0:   3x² − 20x − 20 = 0
x1,2 = (20 ± √(400 + 240)) / 6 = (20 ± √640) / 6 ≈ (20 ± 25,3) / 6
x1 ≈ −0,88 (unzulässig);   x2 ≈ 7,55
G″(7,55) ≈ −25,3 < 0 → Maximum
G(7,55) ≈ −430,4 + 570,0 + 151,0 − 200 ≈ 90,6 €
Interpretation: Der maximale Gewinn von ca. 91 € wird bei einer Produktion von ca. 7,5 Stück erreicht. In der Praxis würde man auf ganze Stückzahlen runden und z. B. x = 7 oder x = 8 Stück produzieren und den Gewinn für beide Werte vergleichen.
Vorgehen: 1. E(x) = p(x)·x bestimmen  ·  2. G(x) = E(x) − K(x) bilden  ·  3. G′(x) = 0 setzen → mögliche Maxima  ·  4. G″(x*) < 0 prüfen  ·  5. G(x*) berechnen.
