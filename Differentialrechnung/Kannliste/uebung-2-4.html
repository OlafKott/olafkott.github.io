ÜBUNG 2.4 · EXTREM- UND WENDEPUNKTE

Wendepunkte berechnen

Berechne alle Wendepunkte der Funktionen.

Aufgabenstellung
Bestimme jeweils alle Wendepunkte der Funktion. Prüfe die hinreichende Bedingung mit der 3. Ableitung.
Hilfsmittel: Diese Aufgabe kannst du sowohl oHiMi (ohne Hilfsmittel) als auch mit dem CAS lösen.
a)
f(x) = x³ − 3x² + 4
b)
f(x) = ⅓x³ − 2x² + 3x + 1
c)
f(x) = 0,5x⁴ − 3x² + 1
d) — Anwendung
Die Kostenfunktion eines Betriebs lautet K(x) = x³ − 9x² + 30x + 50 (x in ME, K in GE). Bestimme den Wendepunkt und interpretiere ihn (Stichwort: Stelle des geringsten Kostenanstiegs).
Lösungen
a) f(x) = x³ − 3x² + 4
f′(x) = 3x² − 6x;   f″(x) = 6x − 6;   f‴(x) = 6

Notwendige Bedingung: f″(x) = 0
6x − 6 = 0 → xW = 1

Hinreichende Bedingung: f‴(1) = 6 ≠ 0 → Wendepunkt
f(1) = 1 − 3 + 4 = 2 → WP(1 | 2)
b) f(x) = ⅓x³ − 2x² + 3x + 1
f′(x) = x² − 4x + 3;   f″(x) = 2x − 4;   f‴(x) = 2

Notwendige Bedingung: f″(x) = 0
2x − 4 = 0 → xW = 2

Hinreichende Bedingung: f‴(2) = 2 ≠ 0 → Wendepunkt
f(2) = 8/3 − 8 + 6 + 1 = 5/3 ≈ 1,67 → WP(2 | 5/3)
c) f(x) = 0,5x⁴ − 3x² + 1
f′(x) = 2x³ − 6x;   f″(x) = 6x² − 6;   f‴(x) = 12x

Notwendige Bedingung: f″(x) = 0
6x² − 6 = 0 → x² = 1 → x1 = −1; x2 = 1

Hinreichende Bedingung:
f‴(−1) = −12 ≠ 0 → Wendepunkt; f(−1) = 0,5 − 3 + 1 = −1,5 → WP(−1 | −1,5)
f‴(1) = 12 ≠ 0 → Wendepunkt; f(1) = 0,5 − 3 + 1 = −1,5 → WP(1 | −1,5)
d) Kostenfunktion K(x) = x³ − 9x² + 30x + 50
K′(x) = 3x² − 18x + 30;   K″(x) = 6x − 18;   K‴(x) = 6

Notwendige Bedingung: K″(x) = 0
6x − 18 = 0 → xW = 3

Hinreichende Bedingung: K‴(3) = 6 ≠ 0 → Wendepunkt
K(3) = 27 − 81 + 90 + 50 = 86 → WP(3 | 86)
Interpretation: Bei einer Produktionsmenge von x = 3 ME ist der Kostenzuwachs am geringsten (Minimum der Grenzkosten). Hier wechselt der Kostenverlauf von degressiv (sinkende Zuwächse) zu progressiv (steigende Zuwächse). Die Gesamtkosten betragen an dieser Stelle 86 GE.
Vorgehen: 1. f″(x) und f‴(x) bilden  ·  2. f″(x) = 0 setzen → mögliche Wendestellen  ·  3. f‴(xW) ≠ 0 prüfen  ·  4. y-Wert mit f(xW) berechnen.
