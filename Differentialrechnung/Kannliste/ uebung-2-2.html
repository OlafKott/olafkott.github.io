ÜBUNG 2.2 · EXTREM- UND WENDEPUNKTE

Extrempunkte berechnen

Berechne alle Extrempunkte (Hoch- und Tiefpunkte) der Funktionen.

Aufgabenstellung
Bestimme jeweils alle Extrempunkte der Funktion. Gib die Art (Hoch- oder Tiefpunkt) an und prüfe die hinreichende Bedingung mit der 2. Ableitung.
Hilfsmittel: Diese Aufgabe kannst du sowohl oHiMi (ohne Hilfsmittel) als auch mit dem CAS lösen.
a)
f(x) = x³ − 3x² + 4
b)
f(x) = −x³ + 3x² + 9x − 1
c)
f(x) = ⅓x³ − 2x² + 3x
d)
f(x) = 0,25x⁴ − 2x² + 3
e) — Anwendung
Die Gewinnfunktion eines Unternehmens lautet G(x) = −0,1x³ + 3x² − 15x + 5 (x = Stückzahl in 1000, G in 1000 €). Berechne, bei welcher Stückzahl der Gewinn maximal ist und wie hoch dieser Gewinn ausfällt.
Lösungen
a) f(x) = x³ − 3x² + 4
f′(x) = 3x² − 6x = 3x(x − 2)
f″(x) = 6x − 6

Notwendige Bedingung: f′(x) = 0
3x(x − 2) = 0 → x1 = 0; x2 = 2

Hinreichende Bedingung:
f″(0) = −6 < 0 → Hochpunkt; f(0) = 4 → HP(0 | 4)
f″(2) = 6 > 0 → Tiefpunkt; f(2) = 8 − 12 + 4 = 0 → TP(2 | 0)
b) f(x) = −x³ + 3x² + 9x − 1
f′(x) = −3x² + 6x + 9 = −3(x² − 2x − 3)
f″(x) = −6x + 6

Notwendige Bedingung: f′(x) = 0
x² − 2x − 3 = 0 → x1 = −1; x2 = 3

Hinreichende Bedingung:
f″(−1) = 12 > 0 → Tiefpunkt; f(−1) = 1 + 3 − 9 − 1 = −6 → TP(−1 | −6)
f″(3) = −12 < 0 → Hochpunkt; f(3) = −27 + 27 + 27 − 1 = 26 → HP(3 | 26)
c) f(x) = ⅓x³ − 2x² + 3x
f′(x) = x² − 4x + 3
f″(x) = 2x − 4

Notwendige Bedingung: f′(x) = 0
x² − 4x + 3 = 0 → x1 = 1; x2 = 3

Hinreichende Bedingung:
f″(1) = −2 < 0 → Hochpunkt; f(1) = ⅓ − 2 + 3 = 4/3 ≈ 1,33 → HP(1 | 4/3)
f″(3) = 2 > 0 → Tiefpunkt; f(3) = 9 − 18 + 9 = 0 → TP(3 | 0)
d) f(x) = 0,25x⁴ − 2x² + 3
f′(x) = x³ − 4x = x(x² − 4) = x(x − 2)(x + 2)
f″(x) = 3x² − 4

Notwendige Bedingung: f′(x) = 0
x1 = −2; x2 = 0; x3 = 2

Hinreichende Bedingung:
f″(−2) = 8 > 0 → Tiefpunkt; f(−2) = 4 − 8 + 3 = −1 → TP(−2 | −1)
f″(0) = −4 < 0 → Hochpunkt; f(0) = 3 → HP(0 | 3)
f″(2) = 8 > 0 → Tiefpunkt; f(2) = 4 − 8 + 3 = −1 → TP(2 | −1)
e) Gewinnfunktion G(x) = −0,1x³ + 3x² − 15x + 5
G′(x) = −0,3x² + 6x − 15
G″(x) = −0,6x + 6

Notwendige Bedingung: G′(x) = 0
−0,3x² + 6x − 15 = 0  |  · (−1/0,3)  →  x² − 20x + 50 = 0
x1,2 = 10 ± √(100 − 50) = 10 ± √50 ≈ 10 ± 7,07
x1 ≈ 2,93;   x2 ≈ 17,07

Hinreichende Bedingung:
G″(2,93) = 4,24 > 0 → Tiefpunkt (uninteressant)
G″(17,07) = −4,24 < 0 → Hochpunkt → Gewinnmaximum
G(17,07) ≈ −0,1 · 4978 + 3 · 291,4 − 15 · 17,07 + 5 ≈ 121,2
Interpretation: Bei einer Stückzahl von ca. 17 070 Stück erzielt das Unternehmen den maximalen Gewinn von ca. 121 200 €.
Vorgehen: 1. f′(x) und f″(x) bilden  ·  2. f′(x) = 0 setzen → mögliche Extremstellen  ·  3. Vorzeichen von f″ prüfen (HP/TP)  ·  4. y-Wert mit f(xE) berechnen.
