ÜBUNG 3.2 · GAUSS-VERFAHREN

LGS mit Gauß-Verfahren lösen

Bestimme die Funktionsgleichung der ganzrationalen Funktion 3. Grades.

Aufgabenstellung
Stelle für jede Aufgabe das LGS auf und löse es mit dem Gauß-Verfahren (oder dem CAS). Gib die Funktionsgleichung an.
Hilfsmittel: Diese Aufgabe kannst du sowohl oHiMi (mit Gauß-Verfahren per Hand) als auch mit dem CAS lösen.
a)
Gegeben sind die Punkte A(−1 | 0), B(0 | 1), C(1 | 0), D(2 | 3).
Bestimme die ganzrationale Funktion 3. Grades.
b)
Gegeben sind die Punkte A(−2 | −2), B(0 | 0), C(1 | −2), D(2 | 2).
Bestimme die ganzrationale Funktion 3. Grades.
c) — Anwendung
Bei einer Fischpopulation in einem Teich wurde der Bestand zu vier Zeitpunkten gemessen:
Jahr t 0 1 3 4
Bestand B (in 100 Stück) 4 8 4 8
Bestimme eine ganzrationale Funktion 3. Grades B(t), die diese Daten beschreibt.
Lösungen
a) A(−1 | 0), B(0 | 1), C(1 | 0), D(2 | 3)
LGS:
I: −a + b − c + d = 0
II: d = 1
III: a + b + c + d = 0
IV: 8a + 4b + 2c + d = 3

Lösung (per Hand mit Gauß):
Aus II: d = 1.
I + III: 2b + 2d = 0 → 2b + 2 = 0 → b = −1
III − I: 2a + 2c = 0 → a = −c
In IV: 8a + 4·(−1) + 2c + 1 = 3 → 8a + 2c = 6 → 4a + c = 3
Mit a = −c: 4(−c) + c = 3 → −3c = 3 → c = −1; a = 1

→ f(x) = x³ − x² − x + 1
b) A(−2 | −2), B(0 | 0), C(1 | −2), D(2 | 2)
LGS:
I: −8a + 4b − 2c + d = −2
II: d = 0
III: a + b + c + d = −2
IV: 8a + 4b + 2c + d = 2

Lösung:
Aus II: d = 0.
I + IV: 8b = 0 → b = 0
III: a + c = −2
IV: 8a + 2c = 2 → 4a + c = 1
(4a + c) − (a + c) = 1 − (−2) → 3a = 3 → a = 1; c = −3

→ f(x) = x³ − 3x
c) Fischpopulation im Teich
Punkte: (0 | 4), (1 | 8), (3 | 4), (4 | 8)
LGS:
I: d = 4
II: a + b + c + d = 8
III: 27a + 9b + 3c + d = 4
IV: 64a + 16b + 4c + d = 8

Lösung:
Aus I: d = 4. Setze in II, III, IV ein:
II′: a + b + c = 4
III′: 27a + 9b + 3c = 0  |  : 3  →  9a + 3b + c = 0
IV′: 64a + 16b + 4c = 4  |  : 4  →  16a + 4b + c = 1

III′ − II′: 8a + 2b = −4 → 4a + b = −2
IV′ − II′: 15a + 3b = −3 → 5a + b = −1
(5a + b) − (4a + b) = −1 − (−2) → a = 1
→ b = −2 − 4 = −6; aus II′: c = 4 − 1 − (−6) = 9

→ B(t) = t³ − 6t² + 9t + 4
Interpretation: Die Funktion beschreibt einen Bestand, der zunächst von 400 auf 800 Fische steigt, dann wieder fällt (vermutlich durch Überpopulation/Krankheit) und schließlich wieder wächst.
Tipp: Wenn ein Punkt P(0|y) gegeben ist, ergibt sich sofort d = y. Das vereinfacht das LGS erheblich.
